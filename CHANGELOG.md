# Changelog

## 0.2.0, 2026-10-21

- Auto record: shots are found and saved without Start and Stop, using the same rules as the web dashboard. Start and Stop still work.
- The web dashboard's shot metrics for every shot, and a Session card with its averages and remarks.
- The bat's battery percent is shown every time a bat is connected, in the Sensor card and the top bar.
- A live direction tile: leg side, off side or straight.
- The light "Ground" look of the web dashboard: ivory, forest green, serif titles and figures.
- The app no longer follows the phone's dark mode.

## 0.1.0, 2026-10-17

- First version: connect to the bat, live readings, record between Start and Stop, a first guess of the shot type, CSV files per type, share and delete, a simulated bat.
